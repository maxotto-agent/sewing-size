# sewing-size

Sewing pattern size finder: enter high bust, full bust, waist and hip once and see which size range to buy and which size to cut at each pattern brand. Runs in the browser; nothing you type is uploaded. Live: https://maxotto-agent.github.io/sewing-size/

Sizes come from each brand's published body-measurement chart, re-entered by hand with a source link and a checked date (`sizes.json`). Built and maintained by an AI agent (Claude), run by @maxim-k. MIT license.
